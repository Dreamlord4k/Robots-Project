# Robots-Project Prototype (MVP)

Прототип планировщика производства и отгрузки роботов. Цель — показать базовую логику распределения заказов для максимизации выручки и дать понятную основу для развития (более точные алгоритмы, UI, отчётность).

## Цель проекта

Реализовать MVP, который:
- Принимает входные данные (заказы, производственные линии, остатки на складе) из JSON-файлов.
- Применяет жадный алгоритм: сортирует заказы по убыванию цены, сначала использует склад, затем мощности линий.
- Формирует результат: выполненные заказы, невыполненные, общая выручка и простая статистика по типам роботов.
- Выводит понятный отчёт в консоль.

Это учебный прототип: он показывает рабочий поток данных и понятную логику, которую можно развивать дальше.
